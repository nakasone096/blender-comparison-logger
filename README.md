# blender-comparison-logger

3DCG学習支援アドオンの比較実験（アドオン版 vs 既存学習方法：動画版）で使う、**両群共通の確認テスト**と、
**動画版の学習中の操作ログ記録**を行うアドオンです。

- **確認テスト（両群共通）**：学習後に同じ課題を解き、成否・所要時間・Undo回数を記録します。判定の実装はこのアドオンだけにあり、両群が同じ基準で測定されます。テスト中はヒント・解説は一切出ません。
- **学習中の計測（動画版のみ）**：動画を見ながら作業している間の操作を、裏で検知して記録します（画面には進捗を出しません）。

## 導入方法

1. 「Code」→「Download ZIP」でこのリポジトリをダウンロード（解凍せず、そのままデスクトップに置く）
2. Blenderの環境設定 → アドオン → 右上「∨」→「ディスクからインストール」でZIP本体を選択
3. 3Dビューのサイドバー（Nキー）→「Logger」タブを開く

ログの保存先フォルダは、デスクトップに「学籍番号_群」（例：`23DB999_video`）が**自動で作られます**。
手動でのフォルダ作成・名前変更は不要です（アドオン版の参加者は、現行アドオンが作った `23DB999_addon` が、そのまま使われます）。

## 使い方

1. 「参加者ID」を入力し、「群」を選ぶ（動画版／アドオン版）。「ログ保存フォルダ」は**空欄のままでよい**（必要なら「フォルダを自動作成」で先に作れる）
   ※ログ保存フォルダの選択ボタン（Blenderのファイルブラウザ）は、環境によってBlenderが落ちるため用意していません
2. **動画版のみ**：学習を始める前に「計測開始」を押し、学習が終わったら「計測終了」を押す
3. 学習後に「テスト開始」を押す。課題が1問ずつ表示される
   - 練習課題 → 課題1〜6 → 総合課題の順（各課題の制限時間は3分、総合課題は5分）
   - 条件を満たすと自動で完了と判定され、「次の課題へ」で進む
   - 分からない時は「分からない（次へ）」で飛ばせる。立方体を消してしまった時は「シーンをやり直す」
4. 終了後は、ログ保存フォルダをそのままZIP圧縮してアップロードする（フォルダ名がそのままファイル名になる）

記録されるファイル名（群のタグが自動で入ります）：

| 内容 | ファイル名 |
|---|---|
| 学習中の計測（動画版） | `学籍番号_video_日時.jsonl` |
| 確認テスト | `学籍番号_video_test_日時.jsonl` ／ `学籍番号_addon_test_日時.jsonl` |
| 確認テストの結果（1人分・自動作成） | 上の `.jsonl` と同じ名前の `.test_summary.csv` |
| 学習中の計測の結果（動画版・自動作成） | 上の `.jsonl` と同じ名前の `.category_summary.csv` |

CSVは「テストを終了する」「計測終了」を押した時に自動で作られます。パネルの「結果CSVを再出力」ボタンで作り直せます。
テスト終了時には、ログフォルダのZIP圧縮→アンケート回答→ZIPアップロードの手順がポップアップで表示されます。

## 集計

`tools/` 内のスクリプトで、記録したJSONLログをCSVに集計できます（実験者用）。

```
# 確認テスト（両群）：フォルダ内の *_test_*.jsonl を全員分まとめて1つのCSVに
python jsonl_to_test_summary_csv.py <jsonlが入っているフォルダ>
python jsonl_to_test_summary_csv.py <xxx_test_xxx.jsonl>

# 学習中の計測（動画版）
python jsonl_to_category_summary_csv.py <participant_log.jsonl>
python jsonl_to_category_summary_csv.py <jsonlが入っているフォルダ>
```
